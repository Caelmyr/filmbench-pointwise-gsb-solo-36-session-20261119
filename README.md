# FilmBench 彩色负片工作台

FilmBench 从一张扫描负片取样，将橙色片基下的各通道透射值映射成相对密度，再显影出可下载的正片。原始上传文件与原片坐标独立保留。

## 启动

```sh
docker compose up -d --build
```

打开 `http://127.0.0.1:18939/`。服务默认只绑定本机，容器数据保存在独立的 `filmbench-data` 卷。也可在 Python 3.11 或 3.12 环境中安装 `requirements.txt` 后运行 `python -B app.py`。本地进程默认写入 `data/`，可通过 `FILMBENCH_DATA_DIR`、`FILMBENCH_HOST`、`PORT` 调整。

## 操作

1. 点击“载入港湾日落”，或导入 PNG、JPEG、单页 TIFF。两份演示均为合成图，雨夜市集保留了已知位置的码值截断和灰尘。
2. 翻拍底片时若灯箱照明不均（暗角、缓慢偏色），保持相机不动空拍一张灯箱，在“灯箱平场”中上传。空拍须与扫描同尺寸，按当前扫描编码解释；灰尘、过曝块等局部异常会先就地修复再生成增益场，不会在正片上留下反印，而缓慢的照明渐变会完整保留并被校正。可随时移除空拍恢复直接显影。
3. 根据扫描文件来源选择 sRGB 或线性 RGB。使用“选透光片边”在完整原片中框出未曝光的胶片片基。未指定区域时，使用片边较亮样本的稳健初估，再用载入正片核对。
4. 调整显影的黑点、白点、曝光、对比或分通道偏置后应用。切换原片和正片同位对照、相对密度或扫描截断图。蓝色表示零值，橙红表示满量程，紫色表示同点有两类截断。
5. 框选画格，按需旋转、镜像。探针在完整原片上读取扫描码值和对应的正片颜色，右下放大像素周围的纹理。单次点修补用手工来源和目标、原片像素半径，替代目标的少量像素。
6. 从当前画格下载 8 位正片 PNG、16 位 RGB 正片 TIFF 或 16 位灰度相对密度 PNG，与正片预览走同一条显影管线。下载扫描原档会给出未修改的上传字节。导出的工程 ZIP 含空拍（若已附加），可在“恢复工程 ZIP”另建项目并重现当前设置。图像准备入口可单独运行通用帧处理和图像校正。

## 图像约定

- 接受 8 位或 16 位的无符号 RGB、灰度扫描。灰度会扩展为三个通道。最大 28 MB、有效像素 650 万，任一边长限 6500，短边至少 16。透明、别的色彩模型和多页 TIFF 需先在扫描软件中转换。使用输入设置解释颜色，不执行机身 RAW 解码或 ICC 颜色管理。按原生像素顺序读入，成片方向可在工作台调整。
- 片基、裁切和修补坐标都在未转向的原片上，以左上为起点。裁切、转向和镜像只作用于成片和同位对照。扫描截断诊断始终依据完整原档的码值。直方图可查看完整扫描的码值或当前画格显影后的线性值，大图使用规则采样计算直方图。
- 片基校准以线性透射率和所选区域中值为基础。密度使用相对片基的负对数，显示与下载把 0 至 1.6 单位映射为灰阶。正片输出以 sRGB 传递函数编码。结果是基于单一片基的数字显影，取样或扫描截断会影响颜色和能恢复的细节。
- 空拍平场在片基取样之前作用于线性透射值：空拍先按当前扫描编码转为线性，截断像素和相对局部参考明显离群的小区域（灰尘、过曝块）用周围照明修复，再平滑成归一化增益场逐像素相除。增益场只保留大尺度照明结构，缓慢偏色会被校正而不是被当作异常忽略；异常区域占比超过四分之一或空拍过暗时会拒绝附加。
